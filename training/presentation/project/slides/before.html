Why it exists

Grading one assignment took five steps in four systems

Step 1 · GitHub

Copy the fellow’s code

Step 2 · Laptop

Run the tests and write the report

Step 3 · GitHub

Post the feedback

Typed by hand

Step 4 · Google Classroom

Enter the grade

Typed by hand

Step 5 · Salesforce

Enter the grade again

Typed by hand

The same grade and feedback were typed three times, for every fellow, on every assignment. GitHub Classroom, which handed out and collected the work, is also being discontinued.

The point of this slide is the cost to instructors: time spent copying a grade is time not spent reading a fellow's work. Do not explain each tool.
